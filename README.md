# Mi Estudio de Moda y Aventuras

Juego infantil 2D de moda, belleza y aprendizaje temprano para iPad (horizontal). Sin backend, sin anuncios,
sin compras, sin enlaces externos; todo se guarda en el dispositivo.

```bash
npm install
npm run dev      # servidor de desarrollo (accesible en la red local para probar en iPad)
npm test         # pruebas unitarias
npm run build    # compilación de producción en dist/
```

Documentación: `docs/ARQUITECTURA.md`, `docs/PLAN_Y_AGENTES.md`, `docs/DECISIONES.md`, `docs/AGENTES.md`.
